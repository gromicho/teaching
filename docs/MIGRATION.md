# Migration to one public teaching collection

The public ABW, AABW, Heuristics and teaching-foundations collections are consolidated here. Courses are folders, not separate maintained repositories. Instructor material is consolidated independently in private `gromicho/teaching-solutions`; no private repository history is imported into this public repository.

The [import manifest](../provenance/imports.json) records source commits, source paths, file hashes and the destinations of imported resources. It also identifies inputs with local cleanup changes that had not yet been published in the predecessor repositories.

The six predecessor GitHub repositories were deleted on 30 August 2026 after verification of local recovery copies. The maintainer retains complete Git mirrors, standalone bundles, readable restored checkouts and copies of unpublished local edits. Old repository URLs no longer work; use this collection and the separate private solutions repository. Source names and commits in provenance manifests remain historical identifiers, not promises of live links.

Duplicate data and old relocation notebooks are represented by the canonical resources here, not copied into multiple course folders. The old solver-installation experiment is retained in the maintainer's local AABW recovery copy, not in the current learning catalogue. The Alice photograph is not recopied: its creator/licence was unresolved and it is unnecessary for the model. The original Heuristics MIT licence and course-specific attribution notices are retained.

No Dropbox/Overleaf source, solution-bearing course PDF, private book material, personal credentials, or instructor recovery archive is included in this public import. The 2026/27 selection remains a development edition.
